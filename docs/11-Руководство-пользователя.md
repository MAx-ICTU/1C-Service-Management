# 11. Проект руководства R1 v0.2

Формы ещё не созданы, названия соответствуют проекту. После реализации добавить проверенные снимки/команды.

Диспетчер: заполнить Клиенты и Оборудование; создать заявку, описание/контакт/адрес, принять, назначить инженера. После диагностики/работ проверить результат и закрыть. Ошибки обязательности показывают отсутствующее поле; принятая идентификация не меняется.

Инженер: войти собственной учётной записью, открыть свою заявку, начать, записать диагноз/заключение, виды работ/количество/суммарные часы и итог. Черновое сохранение результатов не означает закрытия. Инженер не назначает ответственного и не закрывает заявку в рекомендуемом R1.

Руководитель: читать список/историю оборудования, выбирать период по дате закрытия, расшифровывать работы. Денежных показателей/сроков SLA нет.

Администратор: в Конфигураторе создать пользователей ИБ, назначить роли, связать инженеров с UUID пользователей. Проверять роли последовательным закрытием/входом, не вторым параллельным сеансом. Резервировать перед обновлением.

Закрытая заявка неизменяема. Повторное обращение создаётся новой заявкой со ссылкой на прежнюю. При конфликте версии обновить форму; при отсутствии прав обратиться администратору, а не менять данные регистра вручную.
