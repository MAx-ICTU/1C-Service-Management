## Формы

Справочники — управляемые стандартные формы списка/элемента. Заявка — ФормаДокумента: «Обращение», «Исполнение», «Работы», «История статусов»; ФормаСписка с отборами клиент/оборудование/инженер/статус. Команды «Принять», «Назначить», «Начать», «Закрыть», «Отменить» вызывают единые серверные правила.

Минимальный АРМ — список заявок, без графика загрузки/карт/баллов. Отчёт ИсторияОбслуживанияОборудования на СКД: Оборудование обязательно, НачалоПериода/КонецПериода/Инженер необязательны. Период по дате закрытия; конечная дата включается целиком. Группировки заявка→работы; часы не дублируются при соединении с событиями статусов.
