## Минимальный подтверждённый профиль

| Элемент | Назначение / основание |
|---|---|
| DESIGNER | Режим Конфигуратора; встречается в примерах локальной справки |
| /F <путь к ИБ> | Файловое подключение; присутствует в локальном примере |
| /DumpConfigToFiles <каталог> | Полная выгрузка основной конфигурации |
| -Format Hierarchical | Описан в локальном разделе выгрузки; фиксируем выбранный формат |
| /LoadConfigFromFiles <каталог> | Полная загрузка основной конфигурации; иерархический формат по умолчанию |

Другие параметры справки изучены, но в минимальные команды не включаются. Нет -Server/-JobsCount в файловом учебном контуре, нет -NoCheck (не отключать проверку целостности), -partial/-files/-listFile и инкрементальности в первом цикле. /Out, /CheckConfig и /UpdateDBCfg не приводятся как проверенные команды этого проекта: синтаксическую/конфигурационную проверку и обновление выполняем вручную. Параметры /N и /P не используются в примерах: для первого round-trip берётся отдельная новая учебная ИБ без настроенной аутентификации, далее аутентификация уточняется по справке/диалогу без хранения пароля в Git.

## Формат исходников

Начальный источник — экспорт самого Конфигуратора: Configuration.xml, ConfigDumpInfo.xml и объектные XML/модули/формы/прочие файлы, фактически выданные платформой. Не сочинять структуру XML, xmlns, UUID и номера версий. Путь модуля использовать из реальной выгрузки, не предполагаемый шаблон.

Метаданные/формы создавать через Конфигуратор; после разрешения реализации Codex редактирует выгруженные BSL-тексты, сохраняя экспорт. Удаление объекта фиксировать свежей полной выгрузкой, иначе останутся старые файлы. Готовность формата доказывает round-trip: загрузка → проверка → обновление БД → запуск → повторная выгрузка.

Первый протокол фиксирует exe/version, версию формата, фактические пути, время/сообщения/итог команды, состав дерева/UUID, различия повторной выгрузки. Бинарное совпадение всех файлов не обещается: служебные изменения анализируются отдельно. Если CLI не сработал, записать точную ошибку и использовать ручной экспорт, а не придумывать параметр.
