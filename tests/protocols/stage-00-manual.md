# Ручная часть stage-00: требуется пользователь

Средство управления Windows у Codex технически не запускается. Базы уже созданы, повторно CREATEINFOBASE выполнять не нужно. Документ не подтверждает выполненные UI-проверки.

## 1. Откройте существующую базу разработки

Корень проекта:
C:\Users\maksi\Documents\Codex\2026-10-08\files-pasted-by-the-user-1-2\outputs

База разработки:
C:\Users\maksi\Documents\Codex\2026-10-08\files-pasted-by-the-user-1-2\outputs\ib\dev

В списке запуска 1С: «Добавить» → «Добавление в список существующей информационной базы» → имя «СервисТех — учебная разработка» → на данном компьютере → каталог выше. Выберите учебную 8.5.1.1150 и откройте Конфигуратор. Не выбирайте создание новой базы: текущая dev уже существует. Roundtrip пока не открывайте.

Перед изменением проверьте «О программе»: версия 8.5.1.1150 и файловый путь dev. Если путь другой, дерево содержит чужие объекты или версия отличается — остановитесь и сообщите. Исходные резервные копии уже в backups/stage00-initial; при наличии неожиданной новой активности базу сначала закрыть/сделать дополнительную копию, не перезаписывая исходную.

## 2. Задайте свойства пустой конфигурации

«Конфигурация → Открыть конфигурацию», выделить корень → свойства:
- Имя: УправлениеСервиснойКомпанией.
- Синоним: 1С: Управление сервисной компанией.
- Версия: 0.0.1.
- Основной режим запуска: Управляемое приложение.
- Режим совместимости: не менять исходный, записать фактическое значение.

Не добавляйте справочники, документы, регистры, формы, роли и текст модулей.

## 3. Создайте только подсистему

«Общие → Подсистемы» → добавить верхнеуровневую подсистему:
- Имя и синоним: Сервис.
- Комментарий: Учебный учёт заявок на обслуживание оборудования.
- Включать в командный интерфейс: Да.
- Состав: пустой.

## 4. Проверьте и обновите

Сохранить конфигурацию. Через меню Конфигурация выполнить штатную проверку конфигурации, записать результат/сообщения. Отсутствие модулей не требует добавления кода ради синтаксической проверки.

Перед обновлением убедиться: корень имеет заданное имя и создана ровно одна подсистема, никаких других новых объектов. «Конфигурация → Обновить конфигурацию базы данных»; просмотреть изменения, подтвердить только ожидаемые. При неожиданном удалении/чужих объектах — остановиться.

Запустить Предприятие для проверки открытия. Пустая подсистема может не показываться без команд — это допустимо. Закрыть Предприятие, затем Конфигуратор. Нельзя оставлять их открытыми перед пакетной выгрузкой.

## 5. Сообщите результаты в чат

1. Версия и полный путь базы из «О программе».
2. Точный режим совместимости.
3. Созданы ли корень/Сервис с указанными свойствами, пустой ли состав, пусты ли модули.
4. Результат проверки конфигурации и обновления БД: без ошибок либо точные сообщения.
5. Открылось ли Предприятие и закрыты ли теперь все сеансы этой базы.

Можно приложить снимки дерева/свойств/результатов проверки. Не нужно создавать XML вручную, присылать 1CD или переходить к справочникам.

После вашего сообщения Codex выполнит доступные пакетные операции над фактической конфигурацией: резервирование, полную выгрузку, сохранение src/config, загрузку в отдельную roundtrip, сравнение экспорта. Визуальная проверка roundtrip/запуска может также потребовать вашего участия; она будет явно отмечена.
