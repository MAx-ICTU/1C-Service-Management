# 07. Техническое задание v0.2

## Принятые уточнения

Пользователь установил среду 8.5.1.1150 учебная, Windows, файловую ИБ, один сеанс, Конфигуратор, отсутствие EDT, промышленной эксплуатации и полноценных конкурентных проверок. Объём R1 — документ 05; склад, расчёты, автоматический SLA, ТО/сложные интеграции отложены. Старые вопросы v0.1 о выборе текущей платформы/СУБД больше не блокируют R1.

Текущий результат — обновлённая документация и план первого задания. Программирование/создание объектов запрещены до завершения ревью и утверждения первого этапа пользователем.

## Вопросы и решения, требующие согласования

|---|---|---|---|

| Q-R1-02 | A — закрытие диспетчером, терминальное; B — инженер закрывает; C — переоткрытие | A, инженер записывает результат, диспетчер проверяет | Открыт; переходы/права |
| Q-R1-03 | A — инвентарный номер уникален внутри клиента, серийный предупреждает о дубле; B — обязательный уникальный серийный; C — идентификатор не нужен | A, подходит оборудованию без серийного номера | Открыт; справочник |

## Приёмка R1

Объекты строго по 05; цикл принятие→назначение→работа→закрытие; закрытие без диагноза/итога запрещено; история оборудования достоверна; роли проверены последовательными входами; штатная выгрузка загружается в отдельную тестовую ИБ; нет синтаксических ошибок; нет лишних объектов отложенного контура. R1-TC-01–15 выполнены и имеют протокол. Конкурентность и нагрузка не включаются в утверждение готовности учебного релиза.

Приёмка первого задания — только пустая конфигурация/первая подсистема, см. 15. Нельзя считать выполненным первый рабочий релиз после создания одной подсистемы.
