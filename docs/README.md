# 1С: Управление сервисной компанией

Проектная документация первого этапа. Версия 0.1 от 08.10.2026.

Статус: проект для согласования. Код 1С, конфигурация и интеграции не создавались.

Предложения с идентификаторами Q относятся к неподтверждённым бизнес-правилам. Рекомендуемые варианты используются только для согласованности проектной модели; они не считаются утверждёнными заказчиком. До разработки следует закрыть блокирующие вопросы из документа 07.

## Условные обозначения

BR — бизнес-требование; FR — функциональное требование; NFR — нефункциональное требование; BP — процесс; UC — сценарий; TC — тест; Q — вопрос согласования.

Первый этап фиксирует предварительное проектирование. Детальное проектирование форм, печатных макетов и окончательных метаданных выполняется после согласования, также до программирования. Документы описывают целевое поведение, а не существующую программу.
