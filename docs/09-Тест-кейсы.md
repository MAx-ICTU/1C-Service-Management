# 09. Тестирование R1 v0.2

Тесты будущей конфигурации пока не выполнялись: конфигурация отсутствует. Старые 43 TC v0.1 не являются набором приёмки сокращённого релиза и сохранены в истории/архиве. Проверяем 15 кейсов R1, а конкурентность/большую нагрузку откладываем.

Демоданные: клиент Альфа, оборудование Кондиционер D-001, другой клиент Бета и его оборудование B-001; инженеры Петров/Сидоров с разными пользователями ИБ, неактивный инженер; работа Диагностика, работа Очистка. Учётные записи админ/диспетчер/два инженера/руководитель тестируются по очереди, сеанс закрывается перед новым входом.

Отдельно первый этап без кода проверяется чек-листом 15: он не подтверждает R1-TC-01–14. Конкурентные назначения, блокировки, промышленная нагрузка и автономные регламентные задания — «Отложены», до коммерческого стенда результаты не заявляются.
