# 09. Система тестирования и тест-кейсы

Версия 0.1. Это спецификация будущих проверок. Тесты приложения не запускались: приложение и код отсутствуют. Ожидаемые результаты условны до согласования Q.

## Организация

Уровни: проверка чистых правил SLA/цен/ТО/оценки инженера; интеграционная проверка проведения и отмены; конкурентные проверки в двух сессиях; пользовательские сценарии под каждой ролью; отдельные нагрузка, восстановление и права. Автоматизация выбирается после Q-14/Q-17, исполняемые тесты в текущем этапе не создаются.

Для каждого запуска: версия конфигурации/платформы, СУБД, данные, роль, время/календарь, фактический результат, скриншот или снимок движений, статус (не выполнен/пройден/дефект), номер дефекта. Начальные остатки восстанавливать перед кейсом. Критичны инварианты запасов, долга, прав, дубликатов и срока; все соответствующие кейсы обязательны.

Демо-набор: клиент «Альфа», контакт Иванов, площадка Москва/ЗонаА, Daikin FTXS35 SN-001; инженеры Петров (нужные навыки/зона), Сидоров (без обязательного навыка), Смирнов (занятый интервал); календарь Пн–Пт 09–13/14–18 Europe/Moscow без исключений в тестовой неделе; компрессор 5 шт. по 100; Петров 0; услуга ремонт 1 шт. по 2000; продажа детали 1000; ставка труда Петрова 500/ч. Точные моменты задаются тестовым источником времени, не ручным переводом часов промышленного сервера.

## Дополнительная эксплуатационная приёмка

Нагрузка NFR-02/03 — стенд и профиль документа 03; протокол содержит p95/максимум/ошибки/блокировки. Восстановление NFR-08 — замер RPO/RTO, сверка 5/2/1 складского примера, заявок/долга, файлов и ролей. При закрытых клиентах проверить автономное срабатывание ТО/SLA и восстановление после остановки сервера. Для резервных копий проверить доступ только эксплуатационных учётных записей.

Для календаря дополнительно проверить праздничное исключение, рабочую паузу через обед/выходной и отсутствие паузы реакции; для цен — скидку 100%, нулевую стоимость по договору и копеечное округление. Для рекомендаций — равные баллы и неизвестную территорию. Эти граничные наборы фиксируются внутри соответствующих TC-006/008/014/034, не требуют новой бизнес-логики.
