# 04. Бизнес-процессы v0.2

## Приём

Диспетчер выбирает клиента/его оборудование, контактное имя/телефон, адрес, описание. Черновик может быть неполным. Принятие требует клиента, оборудования, описания, адреса и хотя бы одного способа связи; оборудование активно и принадлежит клиенту. Фиксируются ДатаРегистрации, Новая и история. SLA отсутствует.

## Исполнение

Назначение вручную, без проверки навыков/маршрута/пересечений R1. Инженер должен быть активен и связан с пользователем ИБ. Переназначение до начала с причиной; после начала запрещено. Инженер начинает заявку, вводит диагноз, флаг «не выявлена», заключение, работы и итог. Все результаты хранятся в заявке; отдельные документы диагностики/выполнения пока не нужны. Работа: количество>0, часы≥0.

## Переходы

| Переход | Исполнитель | Проверка |
|---|---|---|
| Черновик → Новая | Диспетчер/админ | Поля приёма, оборудование клиента |
| Новая → Назначена | Диспетчер/админ | Активный инженер с учётной связью |
| Назначена → Назначена | Диспетчер/админ | Смена инженера, причина; факта начала нет |
| Назначена → ВРаботе | Собственный инженер/админ | Фиксация начала |
| ВРаботе → Закрыта | Диспетчер/админ | Заключение/итог, диагноз либо «не выявлена»; ≥1 работа либо пояснение отсутствия при «не выявлена» |
| Черновик / Новая / Назначена → Отменена | Диспетчер/админ | Причина, нет начала/фактических результатов |

Закрыта/Отменена терминальные; факты не редактируются. Во ВРаботе разрешён промежуточный неполный ввод, окончательная полнота проверяется закрытием. После принятия клиент/оборудование не меняются; ошибочное обращение до начала отменяют и создают правильное. Переоткрытие и отмена после начала отложены.

Автор/время события — серверные. История записывается в одной транзакции с заявкой. Повтор команды с тем же идентификатором не создаёт второго события.

## История

Отчёт читает закрытые заявки и их работы, не вторую копию фактов в регистре. Открытые обращения доступны отдельным отбором списка. Повтор — ссылка ПредыдущаяЗаявка, автоматической классификации нет.
